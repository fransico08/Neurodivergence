# UI reference chính

Khi thiết kế, sửa hoặc review giao diện trong dự án này, dùng bộ UI/UX Pro Max cục bộ làm nguồn tham chiếu chính.

## Điểm bắt đầu

- Hướng dẫn và workflow chính: `.agents/skills/ui-ux-pro-max/SKILL.md`
- Danh mục style, màu sắc, typography, UX và app patterns: `.agents/skills/ui-ux-pro-max/data/`
- Hướng dẫn UI styling (Tailwind, shadcn/ui, responsive, accessibility): `.agents/skills/ui-styling/`
- Tokens, component states và component specifications: `.agents/skills/design-system/`

## Quy ước áp dụng

1. Trước khi tạo UI mới, đọc `ui-ux-pro-max/SKILL.md` và chọn dữ liệu phù hợp với loại màn hình/stack đang dùng.
2. Ưu tiên accessibility, responsive design và tính nhất quán với giao diện hiện có.
3. Không coi các dữ liệu trong thư mục này là dependency runtime: chỉ dùng để tham chiếu khi thiết kế và viết mã.
4. Nếu yêu cầu UI mâu thuẫn với guideline, ưu tiên yêu cầu cụ thể của sản phẩm.
